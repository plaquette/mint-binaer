# MINT Klasse 8 · Binärzahlen und der Kartentrick

Interaktives Jupyter-Notebook für den MINT-Unterricht (Sekundarschule Basel-Stadt, Klasse 8).
Thema: Umrechnen Zehner-/Zweiersystem und die Mathematik hinter dem Karten-Zahlentrick.
Nur Python-Standardbibliothek – keine Installation nötig.

## Für die Schülerinnen und Schüler: im Browser starten (Binder)

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/plaquette/mint-binaer/HEAD?labpath=w04-binaer-notebook.ipynb)

Auf den Button klicken → Binder baut eine eigene, private Umgebung (kann beim ersten Start
1–2 Minuten dauern). Jede/r arbeitet in einer eigenen Kopie; niemand ändert die Version anderer.
Kein Login nötig.

**Direktlink:** https://mybinder.org/v2/gh/plaquette/mint-binaer/HEAD?labpath=w04-binaer-notebook.ipynb

## Hinweise
- Zum Behalten der eigenen Arbeit: im Notebook **File → Download** (Binder-Sitzungen sind flüchtig).
- Aufbau: **Teil A** (Demo mit der Lehrperson), **Teil B** (selbst am Rechner),
  **Didaktische Reserve R1–R3** für Schnelle.
